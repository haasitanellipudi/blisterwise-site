# blisterwise.ca

The Blisterwise "coming soon" page with the founding-pharmacy pilot sign-up form.
A single static page (`index.html`), meant for GitHub Pages; `CNAME` points it at blisterwise.ca.

Sign-ups are sent to a Google Apps Script web app in the Blisterwise Google account
(its code is kept in the private app repository under `google-scripts/`).
